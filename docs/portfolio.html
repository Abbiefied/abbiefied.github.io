AdaptEd

An AI-enhanced learning platform for personalised and multimodal learning in higher education. The project uses Python for backend services and PHP for Moodle customizations. Machine learning models (SVD, TF-IDF, Random Forest) are used for content recommendations. Natural language processing techniques are employed for the chatbot and content summarization. The facebook/bart-large-cnn model from HuggingFace Transformers is used for text summarization.

Accident Predictive Modelling

Predictive modelling of highway traffic accidents across Nigeria’s 37 states, using Federal Road Safety data on accident severity combined with a second dataset on causes such as speeding, dangerous driving and overloading. Covers data merging, exploratory analysis and correlation mapping. It then compares SVM regression models (linear, RBF and polynomial kernels, tuned with grid search) and neural networks for predicting total accident cases and severity levels.

Animal Vulnerability Analysis

Analysis of a 196-species animal dataset exploring which biological and ecological traits predict extinction risk. Includes thorough data cleaning (duplicates, unit conversion, family-level imputation) and comparisons of threat levels by diet, social structure, lifespan and weight. Key finding: threatened species live about twice as long on average, which supports the slow life history hypothesis.

Purple Sky

A utilitarian weather application targeting users who require minimal weather information for their day-to-day navigation and schedule. The app provides current weather data, a 3-day weather forecast, air quality information, a weather map with weather icon markers and quality data, the ability to compare weather data between two countries, and the option to add a weather widget to the home screen and weather notifications to the notification bar.
